# Java 专项审查

只看 Java 语义相关的问题，通用正确性按 code-review 处理。

- **异常：** 吞掉异常、捕获过宽（`catch (Exception)`）后继续执行、受检异常被包装后丢失原因、`finally` 里抛异常覆盖原异常。
- **资源：** 流、连接、锁没有在所有分支释放；应使用 try-with-resources 的地方手动关闭。
- **空值：** `Optional.get()` 不判断、返回 null 的集合、自动拆箱导致的 NPE。
- **并发：** 共享可变状态没有同步、`HashMap` 在多线程下使用、双重检查锁缺 `volatile`、线程池任务异常被吞。
- **事务：** Spring `@Transactional` 在同类内部调用不生效、只读事务里写数据、事务里调用外部服务、回滚规则不包含受检异常。
- **框架用法：** Bean 作用域与状态、JPA 懒加载在事务外访问、N+1 查询、`equals`/`hashCode` 与实体主键。

每条问题写清触发条件和会发生什么，例如"两个请求同时更新时，后一个会覆盖前一个的余额"。
